/ 01

Brand

The site has one identity element: a terracotta dot at terminal positions. It stamps the masthead (jmc@constans.dev), the period after every page title, and the trailing punctuation of post bodies. Used sparingly — two stamps per post, total. The dot is the entire brand; everything else is structural typography.

Flourishes

The terracotta dot has two officially-sanctioned forms. .dot colors a literal period (or @) at a terminal position. .qm overlays a small accent disc on top of a question mark's own dot. Both belong only at the end of titles, mastheads, and the trailing punctuation of post bodies.

.dot — period at title scale
..
.qm — accent over '?'
?

The trailing period of a post body is wrapped automatically by the autoscript in _includes/footer.liquid: it walks the last paragraph of .post-body / .wp-body and wraps a terminal . or ? in .dot / .qm. Hand-authored markers win — the script won't double-wrap. 

.dot { color: var(--accent); }

.qm {
  position: relative; display: inline-block;
  line-height: 1; vertical-align: baseline;
}
.qm::after {
  content: ""; position: absolute; left: 50%;
  bottom: var(--qm-bottom, 0.13em);
  width:  var(--qm-w, 0.18em);
  height: var(--qm-h, 0.14em);
  background: var(--accent); border-radius: 50%;
  transform: translateX(calc(-50% + var(--qm-x, 0em)));
}

White paper

A long-form layout with Tufte-style sidenotes — adapted to monospace + terracotta. Used for formal, full-text-on-page publications where .paper (abstract + PDF link) would feel too thin. Lives in whitepaper.css, scoped under .wp so it doesn't disturb the .post / .paper layouts. See determinism-under-load for a populated example.

Layout anatomy
  • Container max-width: 920px, padding-right: 260px reserving the right rail
  • Body column max-width: 55ch, set wider line-height (1.75) and slightly smaller body (0.95rem) than .post
  • Sidenotes float: right; clear: right; margin-right: -260px — float into the reserved rail
  • Mobile (< 880px): rail collapses, sidenotes inline with a left-accent rule
Authoring contract — sidenotes & refs

Source order is the only thing the author manages. The CSS counter increments on each .sn-ref and the following .sidenote reads the same value — so refs and notes auto-match as long as you write them in pairs.

Section auto-numbering

h2 inside .wp-body auto-numbers with § 01, § 02, … via CSS counters. h3 gets 1.1, 1.2, … and resets per h2. No author work required.

Drop cap

First paragraph in .wp-body (or any paragraph tagged .lede) gets a 3.4em terracotta drop cap. Pass data.no_drop: true in front-matter or add .no-drop on the body to suppress.

Watermark overlay

Set data.watermark in front-matter to any word and the whitepaper layout stamps a tiled, diagonal watermark across the whole viewport — for draft, confidential, preview, and similar states. The word is uppercased and drawn as an inline SVG data-URI tile, so it needs no image asset and no JS. Omit the key in production.

Contained demo · the real overlay is position: fixed, full-viewport

Expressing the shape of a software architecture using Category Theory creates a skeleton upon which an LLM can iterate toward an implementation while catching intent drift at checkpoints.

The watermark tiles diagonally at 10% opacity, painted above the text but transparent to pointer events.

  • Front-matter key data.watermark — any word; rendered uppercased
  • Tile: a 200×200 SVG <text>, 30px bold grey, rotate(-45 100 100), centered
  • Overlay: position: fixed; top: 0; left: 0; width: 100%; height: 100%; z-index: 9999; pointer-events: none; opacity: 0.1; background-repeat: repeat
  • Theme-agnostic — fixed grey at 10% reads on both light and dark without referencing a token
  • The one rule in whitepaper.css not scoped under .wp: it's a viewport overlay, so it lives at the top level

Voice & rules

A small set of conventions worth writing down so the system stays the system.

  • Lowercase nav labels (work, writing, portal) — never title case
  • Dates as YYYY mon DD — 2026 may 18 — uppercase, tracked
  • The dot belongs on title-end periods, the @ of the masthead, and the trailing punctuation of post bodies — nowhere else
  • One accent color, one family, one set of borders. Don't introduce a second.
  • Saturated colors are reserved for the accent. Whites and blacks stay warm-neutral; never above 0.02 chroma
  • No icons. No emoji. Punctuation does the visual work where icons might otherwise
  • Borders are 1px hairlines (--rule) by default, 1px --rule-strong only on actionables
  • Animations: transition: color 120ms, border-color 120ms on links. No tween easings, no transforms on hover, no scaling

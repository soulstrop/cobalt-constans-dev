<h2><a href="https://github.com/soulstrop/teamwork-loop">teamwork-loop</a></h2>
<p class="body">A document set for building software one user journey at a time with a collaborator — an AI agent or a new human — who starts every session cold. Context outside the repository does not exist for that collaborator, so the repository carries all of it: each journey runs the same eight-step loop behind one named gate, decisions land as ADRs, and a handoff burns down to zero before every pause. A closing step folds what each journey taught back into the plan that is left. A wizard, <code>teamwork-init</code>, renders the template into a new project.</p>

<h2><a href="https://github.com/soulstrop/pi-agent-space">pi-agent-space</a></h2>
<p class="body">A system designed to efficiently and systematically explore this multidimensional space. By treating the "builder harness" (the Pi platform) and the "user harness" (the package of skills, prompts, and models) as a composed system, this project optimizes the agent's behavior against a graduated problem suite. It finds configurations on the Pareto frontier of trade-offs, like tokens used, dollars spent, scaling slope across problem difficulties, and overall quality.</p>
